# 렌더링 명세

**상태: 설계안.** 현재 코드에는 렌더러가 없다. 이 문서는 [002](milestones/milestone002.md), [004](milestones/milestone004.md), [005](milestones/milestone005.md), [006](milestones/milestone006.md)의 공통 목표를 정리한다.

## 좌표와 프레임

논리 해상도는 양수 정수 너비와 높이다. 원점은 좌상단, x는 오른쪽, y는 아래쪽으로 증가한다. 픽셀 `(x, y)`는 정수 좌표이며 화면 밖 픽셀은 그리지 않는다. 사각형은 `[x, x + width) × [y, y + height)`로 정의하고 폭이나 높이가 0이면 아무 픽셀도 포함하지 않는다. 끝점 계산은 넓은 정수형과 검사된 연산을 사용한다.

게임은 프레임에 명령을 기록한다. backend는 제출 순서를 유지한다. `Clear`는 전체 픽셀을 교체하며 나머지 명령은 아래 합성 규칙을 따른다. 프레임의 명령과 리소스 참조는 실행이 끝날 때까지 유효해야 한다.

## 색상과 메모리

논리 픽셀은 straight-alpha RGBA8 sRGB 바이트다. CPU framebuffer는 연속된 row-major 바이트이며 픽셀 시작 오프셋은 `4 * (y * width + x)`다. 생성 시 너비·높이 0, 크기 곱셈 오버플로와 할당 실패를 오류로 반환한다. 범위 밖 읽기는 값 없음, 쓰기는 무시다. Clear는 모든 픽셀에 정확한 RGBA 값을 기록한다.

### Source-over

입력 채널과 alpha는 0–255 정수이며 연산은 선형 광 변환 없이 sRGB 인코딩 채널 값에서 수행한다. 소스와 목적지 alpha를 각각 `As`, `Ad`, 채널을 `Cs`, `Cd`라고 하면:

```text
A = As * 255 + Ad * (255 - As)
Ao = round(A / 255)
Co = A == 0 ? 0 : round((Cs * As * 255 + Cd * Ad * (255 - As)) / A)
```

양의 정수 나눗셈의 반올림은 분자에 분모의 정수 절반을 더해 계산한다. 중간값은 충분히 넓은 정수형을 사용한다. 이 규칙은 각 RGB 채널에 독립 적용한다. `Clear`는 합성하지 않는다.

예: 투명한 목적지에 불투명 빨강은 `(255, 0, 0, 255)`, 불투명 검정 위 alpha 128의 빨강은 `(128, 0, 0, 255)`이다. 양쪽 alpha가 0이면 결과 RGB와 alpha는 모두 0이다.

## 클리핑과 스프라이트

도형은 framebuffer와 교차한 반열린 범위만 처리한다. 음수 좌표와 전체 화면 밖 도형은 정상 입력이다. 004에서 이미지는 같은 RGBA 표현으로 정규화하고 source rect가 이미지 내부인지 검사한다. 정수 배율, 좌우·상하 뒤집기 및 nearest 샘플링을 지원한다. source가 범위를 벗어나거나 배율이 0이면 오류다. 임의 각도 회전은 해당 단계의 범위 밖이다.

## 화면 표시

물리 창 크기를 `W × H`, 논리 크기를 `w × h`라 할 때 배율은 `min(W / w, H / h)`의 정수 몫이다. 배율이 1 이상이면 논리 픽셀을 정수 배로 복제하고 결과를 창 중앙에 배치한다. 남는 영역은 검정이며 홀수 여백은 왼쪽·위쪽에 작은 쪽을 둔다. 배율이 0이면 잘라내거나 비정수 축소하지 않고 화면을 검정으로 유지한다. 물리 크기가 0인 경우 surface 표시를 중단한다.

마우스 좌표의 역변환은 표시 영역 안에서만 수행한다. 여백이나 배율 0에서는 논리 위치가 없다. DPI 변경이나 창 크기 변경 시 물리 크기 기준으로 viewport를 다시 계산한다.

## 백엔드 동등성 및 오류

CPU는 기준 래스터 결과를 만든다. GPU는 동일 명령과 순서를 사용하며 기본 하드웨어 블렌딩이나 sRGB 변환이 위 정수 규칙과 같다고 가정하지 않는다. 논리 framebuffer를 읽어 CPU 기준과 비교하고 차이가 있으면 구현을 수정한다. 표시 장치의 색 관리까지 완전 일치한다고 보장하지 않는다.

Hybrid는 CPU framebuffer를 GPU 텍스처로 업로드해 nearest로 표시한다. 업로드 정렬과 장치 제한을 검사한다. surface 분실이나 크기 변경은 재구성하고 일시적인 획득 실패는 프레임을 생략할 수 있다. 복구 불가능한 오류는 원인을 보존해 전달한다.

## 검증 기준

1×1 및 큰 크기의 생성, 곱셈 오버플로, 모든 경계의 클리핑, 빈 사각형과 음수 좌표를 검증한다. 투명·불투명·반투명 합성 및 겹치는 명령 순서는 고정된 기대 바이트와 비교한다. 정수 배율 0·1·2와 홀수 여백을 검증한다. 이미지 source와 만료 핸들, resize 및 surface 오류를 검사한다. GPU 비교는 지원 환경에서 논리 픽셀을 읽어 완전 일치 확인하며 환경이 없어 건너뛴 경우 미검증으로 기록한다.
